# RenPyTranslator 3.7.1 — части экспорта: слить и проверить

## Зачем

Большая новелла выгружается частями (`…-part01.txt`, `-part02.txt` …):
агенту так проще, а программа не умирает на 40-мегабайтном файле. Но после
перевода части надо собрать обратно — и хочется быть уверенным, что при
этом ничего не потерялось, не заменилось и не задвоилось.

## «Слить части в один файл»

Вкладка «Литературный текст» → кнопка под галочками экспорта. Выбираете
**любую** часть (или папку) — программа сама находит весь набор по имени.

* шапка с правилами берётся из первой части;
* справочники персонажей/сцен из остальных частей не дублируются;
* **тело копируется дословно** — ни одна строка не пересобирается,
  не переформатируется и не заменяется;
* заголовки `=== файл ===` сохраняются, по ним видно, откуда кусок;
* результат — `renpy_translator_export.txt` рядом с частями.

Тест это фиксирует: тело слитого файла сравнивается с экспортом «одним
файлом» и должно совпасть полностью, до строки.

## «Сверить части»

Проверяет набор частей и, если указана папка игры, сверяет с ней:

| Проверка | Что значит |
|---|---|
| идентификаторы | сколько строк всего, нет ли повторов `[#файл:строка]` |
| `RU:` заполнено / пусто | сколько переведено |
| потеряно | строки, которые есть в игре, но пропали из частей |
| лишние | строки, которых в игре нет (опечатка в `[#…]`) |
| EN отличался | оригинал в файле не совпадает с текстом игры |

Если всё в порядке, в конце: «Всё сходится: ни одна строка не потеряна
и не подменена».

## Командная строка

    RenPyTranslator.exe --game "путь\к\game" --merge-parts "D:\экспорт" ^
        --output "D:\экспорт\all.txt"
    RenPyTranslator.exe --game "путь\к\game" --verify-parts "D:\экспорт"

Порядок работы: экспорт частями → перевод → «Слить части» → «Сверить
части» → «2. Импорт правок в игру» (импорт понимает и одну часть, и
слитый файл, и несколько файлов сразу).
