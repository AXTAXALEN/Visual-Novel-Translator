# RenPyTranslator 3.6.0 — текст, нарисованный картинками

Полная локализация упиралась в то, что часть надписей в новеллах — не текст,
а PNG: логотип на титуле, «Start» поверх арта, подписи кнопок. Их не берёт
ни `translate strings`, ни замена шрифтов. Теперь есть вкладка
**«Текст-картинки»**.

## Как это работает

1. **«Найти картинки с текстом»** — программа проходит по `screen`-блокам
   игры и собирает картинки из `add "gui/title.png"`, `imagebutton …`, а
   также из ссылок через переменные (`define gui.main_menu_background =
   "gui/main_menu.png"` → `add gui.main_menu_background`). Каждая картинка
   получает оценку «похоже на надпись» — по мелким штрихам одинаковой высоты
   и малой доле заливки.
2. **Выбрать картинку** — в превью видно саму картинку (прозрачность —
   в клеточку) и красную рамку предполагаемой надписи. Рамку можно
   перетащить мышью или вписать числами `x / y / ш / в`.
3. **Вписать русский текст**, выбрать шрифт (PT Serif Bold/Regular/Italic
   или свой `.ttf`), размер (пусто — подберётся сам) и цвет.
4. **«1. Сделать картинку»** — рядом с оригиналом появляется
   `gui/title_ru.png` **того же размера** (заливка фона + ваш текст,
   вёрстка игры не едет).
5. **«2. Применить к игре»** — в экране литерал превращается в
   `rt_img("gui/title.png")`. Функция `rt_img` отдаёт русский файл только
   при включённом русском языке: переключились на English — снова оригинал.
6. **«Вернуть исходники»** — экраны восстанавливаются, файлы `_ru`
   удаляются.

## Что ещё внутри

* Служебный файл `game/tl/<язык>/zz_renpy_translator_images.rpy` появляется
  только когда есть замены; реестр — `rt_images.json`.
* Копии изменённых экранов лежат в `game/tl/<язык>/rt_images_backup/*.rpy.bak`.
  Именно `.bak`: файл `.rpy` внутри `game/` Ren'Py загрузил бы как скрипт —
  и игра упала бы на двойном объявлении экранов (этот дефект поймали
  и починили на живом движке до выпуска).
* `style`-блоки не трогаем: там значения вычисляются при `init`, до выбора
  языка — подмена работала бы неправильно.
* CLI для тех же действий:
  `--find-image-text`,
  `--image-replace gui/title.png --image-text "ГЛАВНОЕ МЕНЮ"
  [--image-size 64] [--image-color "#ffffff"] [--image-box x,y,ш,в]
  [--image-font путь.ttf]`,
  `--restore-images`.
